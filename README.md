# triform-lab

**Standalone proof that [Triform](https://github.com/noexcess/triform) works for real adopters** —
a minimal multi-module Spring Boot project that does nothing but depend on `triform-starter-nacos`
and verify the three run forms end-to-end.

中文说明见文末 / Chinese notes at the bottom.

## What it proves

- **Zero wiring**: boot classes are plain `@SpringBootApplication` — no Triform annotations,
  no component-scan config, no glue.
- **One dependency**: every service depends only on `io.triform:triform-starter-nacos`.
- **Three forms, same code**: mono / micro-Dubbo / micro-HTTP all pass with identical business code.

## Layout

| Module | Role | Port (HTTP / Dubbo) |
|---|---|---|
| `lab-api` | contract: `@RemoteFacade interface TinyFacade` (+ Item DTO) | — |
| `lab-provider` | provider: plain `@Service` implementation | 9101 / 20901 |
| `lab-consumer` | consumer: constructor-injects `TinyFacade`, exposes `/lab/ping` and `/lab/echo` | 9102 / 20902 |

## Run

```bash
# 0) install triform (clone the main repo first)
git clone https://github.com/noexcess/triform && cd triform && mvn install

# 1) mono — no infrastructure needed
cd triform-lab
mvn -f lab-consumer/pom.xml spring-boot:run
curl "http://localhost:9102/lab/ping?name=hi"

# 2) micro-Dubbo — needs Nacos
mvn -f lab-provider/pom.xml spring-boot:run -Dspring-boot.run.profiles=micro
mvn -f lab-consumer/pom.xml spring-boot:run -Dspring-boot.run.profiles=micro
curl "http://localhost:9102/lab/ping?name=hi"

# 3) micro-HTTP — same code, just env vars (see .run configs)
#    TRIFORM_RPC_TRANSPORT=http (+ provider: TRIFORM_RPC_HTTP_EXPOSE=true, both: TRIFORM_RPC_INTERNAL_TOKEN)
```

`.run/` contains ready-made IDEA configurations: `[LAB-1/2]` (dubbo) and `[LAB-1h/2h]` (HTTP).

## Acceptance history

Every fix round was verified here first: zero-wiring boot, contract index auto-generated by
`triform-indexer`, DTO round-trip with `LocalDateTime` (proves shared host ObjectMapper on
encode+decode), context-path auth, service-name metadata discovery without manual mapping.
